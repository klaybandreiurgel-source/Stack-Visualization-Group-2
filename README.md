# Description
The Stack Visualization System is a Java Swing application that demonstrates how an array-based stack works. It follows the Last-In, First-Out (LIFO) principle and displays stack elements as graphical blocks

# Features

Push an integer onto the stack.

Pop the top element.

Peek at the top element without removing it.

Clear all stack elements.

Check whether the stack is empty.

Generate a random stack containing 1–10 integers.

Display the current stack size.

Show overflow and underflow messages.

Visually identify the top element.
